# Classroom Emotion 项目使用说明

## 项目简介

本项目是一个面向课堂视频或摄像头的离线人脸跟踪与可观察线索分析 PoC。程序检测人脸、关联匿名轨迹、估计表情概率，并将一段时间内的信息融合成需要人工核实的候选线索。它不识别姓名，也不应单独用于评价学生的注意力、理解能力或心理状态。

默认检测器为 YuNet，表情模型为 HSEmotion `enet_b0_8_best_vgaf`（224×224），跟踪由 ByteTrack 完成。SCRFD 后端可选，但需要自行提供并审核模型权重。

## 目录结构

```text
configs/default.yaml               默认输入、模型、频率与时序参数
models/manifest.yaml                模型来源、输入信息与许可备注
models/weights/                    本地模型权重（不随 Git 提交）
src/classroom_emotion/              项目 Python 源码
  detection/                       人脸检测、关键点、姿态及面部线索
  inference/                       表情推理、批处理与人脸特征
  tracking/                        ByteTrack 适配
  cli.py                            命令行入口
  pipeline.py                       逐帧分析流程
  state_fusion.py                   候选状态融合
  output.py                         JSONL 与可选 HTTP 输出
dashboard.py                        Streamlit 浏览器摄像头看板
tests/                              单元与集成测试
docs/architecture.md                系统架构说明
```

模型权重需要单独获取，程序不会在运行时自动下载。模型来源、校验信息和许可备注见 [`models/manifest.yaml`](../models/manifest.yaml)。源码许可不一定覆盖预训练权重或训练数据的使用条款。

## 处理流程

1. 从视频文件、本机摄像头或浏览器摄像头读取帧。
2. 按配置间隔检测人脸；默认将画面划成 2×2 重叠区域分别检测。
3. ByteTrack 每帧更新轨迹。轨迹 ID 是本次运行内的匿名编号。
4. 在指定帧裁剪人脸；存在有效五点关键点时先对齐，失败时退回人脸框裁剪，再交给表情分类器。
5. 按轨迹聚合表情概率和可用面部线索。MediaPipe Face Landmarker 可提供闭眼、眉部下压线索；五点关键点用于粗略头部姿态线索。
6. 通过阈值、持续时间和状态融合生成候选状态，写入 JSONL；可选写出标注视频或推送匿名 JSON。

默认每 2 帧检测一次、每 6 帧进行一次表情推理。状态窗口为 3 秒、至少 4 次有效观察，新状态需保持 1.2 秒才切换。摄像头可以协商成低于配置的分辨率或帧率，应以实际收到的画面规格为准。

## 环境安装

要求 Python 3.11 至 3.13。Windows PowerShell 示例：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e ".[dev,inference,tracking,dashboard]"
```

真实检测和推理需要 `inference`，ByteTrack 需要 `tracking`，浏览器看板需要 `dashboard`。

## 常用命令

### 检查 OpenVINO 设备

```powershell
classroom-emotion probe --device GPU
```

设备被 OpenVINO 枚举到，不等于整条管线已达到实时性能。

### 合成视频验证（不需模型权重）

```powershell
classroom-emotion make-sample --output samples/classroom_sample.mp4 --seconds 4 --faces 6
classroom-emotion analyze --input samples/classroom_sample.mp4 --output outputs/sample.jsonl --annotate outputs/sample_annotated.mp4 --synthetic
```

合成模式只检查视频读写和管线，不代表真实检测或情绪识别效果。

### 分析视频文件

```powershell
classroom-emotion analyze --input classroom.mp4 --output outputs/predictions.jsonl --detector-model models/weights/yunet.onnx --emotion-model models/weights/hsemotion.onnx --device GPU
```

若使用导出的 OpenVINO 情绪模型，将 `--emotion-model` 指向 `models/weights/hsemotion_openvino.xml`。

### 分析本机摄像头

```powershell
classroom-emotion analyze --camera 0 --output outputs/live_predictions.jsonl --detector-model models/weights/yunet.onnx --emotion-model models/weights/hsemotion.onnx --device GPU
```

按 `Ctrl+C` 停止；`0` 通常是系统默认摄像头索引。

### 启动浏览器看板

```powershell
streamlit run dashboard.py --server.address 127.0.0.1 --server.port 8501
```

打开 Streamlit 输出的本机地址并授权摄像头。默认请求 2560×1440、30 FPS，但设备可能协商为较低规格；看板会显示实际收到的画面尺寸。浏览器帧会发送到运行看板的主机进行推理。看板没有用户认证，不要暴露到公共网络；跨设备访问需 HTTPS，并限制在可信网络内。

### 导出 OpenVINO IR

```powershell
classroom-emotion export-openvino --model models/weights/hsemotion.onnx --output models/weights/hsemotion_openvino.xml --precision FP16
```

命令生成同名 `.xml` 和 `.bin`，并输出模型输入形状。该转换不改变模型架构：当前模型仍是 224×224 HSEmotion `enet_b0_8_best_vgaf`，不是 MobileNetV3 112×112。

### 评估人工标注

CSV 必须包含 `frame_index,track_id,state` 三列，每行一条人工标注；轨迹 ID 只在同一次分析中有效。

```powershell
classroom-emotion evaluate --predictions outputs/predictions.jsonl --annotations outputs/annotations.csv
```

此评估衡量状态映射与标注的一致性，不衡量漏检、跟踪 ID 切换，也不能证明识别了学生的真实心理状态。

### 运行测试

```powershell
python -m pytest
```

## 配置说明

主配置为 [`configs/default.yaml`](../configs/default.yaml)，CLI 可用 `--config` 指定其他 YAML。

| 配置区 | 主要参数 | 默认值或作用 |
| --- | --- | --- |
| `input` | `width`、`height`、`fps` | 请求 2560×1440、30 FPS，不保证设备能力。 |
| `runtime` | `device`、`precision` | OpenVINO 默认设备 GPU，配置精度 FP16。 |
| `detection` | `model`、`interval_frames`、切片行列 | YuNet；每 2 帧检测，2×2 重叠切片。 |
| `tracking` | 算法、缓冲与身份保留时长 | ByteTrack；人脸特征重识别最多默认保留 60 秒。 |
| `emotion` | `model`、`interval_frames`、`input_size` | HSEmotion；每 6 帧推理，输入尺寸 224。 |
| `face_cues` | `enabled`、`model` | 可选 MediaPipe Face Landmarker。 |
| `cue_decision` | 各线索阈值与持续时间 | 控制眉部、闭眼、低头候选的触发。 |
| `temporal` | 窗口、最小观察数、切换持续时间 | 3 秒窗口、至少 4 次观察、切换保持 1.2 秒。 |
| `output` | `jsonl_path`、`save_video` | 默认写 `outputs/predictions.jsonl`；默认不保存视频。 |

## 输出数据

JSONL 是 UTF-8 文本，每行一个 JSON 对象。常见字段：

| 字段 | 含义 |
| --- | --- |
| `track_id` | 本次分析中的匿名轨迹 ID。 |
| `frame_index`、`timestamp_seconds` | 帧序号与时间戳。 |
| `box` | 人脸框坐标。 |
| `state` | 融合状态，例如 `engaged`、`head_down_cue`、`phone_use_cue`、`unknown`。 |
| `probabilities` | 表情分类器输出概率。 |
| `observation_count` | 当前轨迹窗口参与估计的观察数。 |
| `facial_cues`、`evidence` | 可用面部线索与触发依据。 |
| `primary_state`、`secondary_state`、`visual_evidence`、`teacher_advice` | 供看板和人工核实使用的说明。 |

记录还包含 `cognitive_load`，当前输入下为“无法判断”。JSONL 不含人脸 embedding；默认不保存原视频。显式使用 `--annotate` 会写出带框视频。可选 HTTP 推送为尽力而为的异步投递：非本机地址必须使用 HTTPS，队列满或网络失败时可能丢记录，应以本地 JSONL 为准。

## 状态解释与限制

- `engaged`、`attentive`、`bored_drowsy_risk` 等是表情或姿态映射出的候选，不是对学生真实状态的判断。
- `head_down_cue` 表示持续低头姿态候选；看材料、书写等也可能触发。
- `phone_use_cue` 是低头、眼睛睁开且中性表情占优时的候选。系统没有手机或手部检测，不能确认手机使用。
- `confusion_cue` 依赖眉部下压等可见线索，不等于模型识别出困惑；当前 HSEmotion 没有 `confused` 类别。
- 持续闭眼不是困倦或睡眠诊断，眨眼或其他原因也可能产生相似线索。
- SCRFD 需要额外权重并须审核模型和数据许可；当前默认仍为 YuNet。
- 当前没有兼容的 MobileNetV3 112×112 权重；不能仅修改 `emotion.input_size` 来切换模型。
- 默认 2×2 检测切片会增加计算量。Arc 140T 上 50 个空白裁剪的批量冒烟数据不是整条管线基准，也不能证明 PTL358h 上的 23 ms 或 40 FPS 目标。

使用课堂视频或人脸特征前，应完成适用的告知、授权、访问控制和数据保留评估。架构细节见 [`docs/architecture.md`](architecture.md)，英文入口与模型获取说明见 [`README.md`](../README.md)。
